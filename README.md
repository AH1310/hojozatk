# منصة حجوزاتك — نظام الصفحات المستقلة لكل صاحب خدمة (QR Code)

- عند دخول أي عميل عبر رمز `QR Code` أو رابط `?page=slug` يفتح له **صفحة حجز مستقلة خاصة بهذا الشخص فقط** ولا يرى أي أشخاص أو صفحات أخرى ولا يستطيع التنقل لخارج هذه الصفحة.
- صاحب الخدمة يدخل أو ينشئ حساباً ليحصل على رابطه المستقل و `QR Code` الخاص به ويدير حجوزات عملائه فقط.

- نفّذ `supabase/schema_strict.sql` في Supabase SQL Editor أولاً.
